Manual do Administrador (CISO / GRC Manager)

1. Acesso Total

Como Administrador (Staff), tens acesso à tab Team (Gestão de Equipa) e ao Django Admin (localizado no canto superior direito, ideal para ações avançadas de base de dados).

2. Gestão de Utilizadores (Team)

  • Criar Utilizadores: Vai a Team -> + Add User. Define o nome, email e uma password temporária.
  • Privilégios:
    • Standard User: Apenas vê e edita o que lhe for atribuído (Riscos, Controlos, etc.).
    • Staff: Acesso ao Django Admin e permissão para gerir a equipa e fazer upload de biblioteca.
    • Superadmin: Acesso total ao sistema e configurações.
Atenção: Nunca apagues o teu próprio utilizador de Superadmin. Cria sempre um utilizador de emergência (break-glass) com as credenciais guardadas num cofre de passwords (ex: Bitwarden).

3. Frameworks e Controlos

  • O sistema já vem com o ISO 27001 e o NIST CSF pré-carregados (com descrições oficiais).
  • Vai a Frameworks para veres os requisitos. Mapeia os teus controlos internos a estes requisitos na página de cada controlo.
  • Coverage: A tab Coverage mostra-te a percentagem de conformidade. Podes exportar este relatório em PDF para apresentar à gestão de topo.

4. Auditorias e Fornecedores

  • Audits: Cria uma auditoria, define o âmbito e adiciona Findings (não conformidades). Gera o relatório PDF no fim para enviar à gestão ou ao auditor externo.
  • Vendors: Avalia os fornecedores. Garante que os fornecedores críticos têm o DPA (Data Processing Agreement) assinado.

5. Configurar o Assistente AI (RAG)

Para o assistente saber responder sobre as regras da empresa:

  1. Vai à tab Assistant.
  2. Faz upload de PDFs de políticas (ex: Política de Segurança da Informação).
  3. O sistema vai ler e "vetorizar" o documento (pode demorar alguns segundos).
  4. A partir daí, qualquer utilizador pode fazer perguntas no chat e a IA responde com base nesse PDF.

6. Backups e Segurança

O sistema já faz backups automáticos! Todos os dias, uma cópia da base de dados e dos ficheiros é guardada na pasta backups/ do servidor.

Recomendação: Descarrega a pasta backups/ semanalmente para o teu OneDrive/Google Drive como backup off-site. Se o servidor for destruído (ex: incêndio), o backup local também se perde.
